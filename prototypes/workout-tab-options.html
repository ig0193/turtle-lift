Workout tab — exercise-first (v2)

Landing finalised (the old E). C, D and F are dropped. Start workout ("Add exercises as you go") opens the exercise picker straight away, and picking an exercise opens the logging screen. The session screen is map-first, and the map resizes with the number of exercises so the list stays reachable. Everything is clickable.

The core loop now
Empty start: Start empty workout → pick exercise → log sets → Mark done → back to the map → Add exercise / pick the next one.
Template start: card → Start → map with the planned list → tap an exercise → log sets → Mark done.
Finish with zero completed sets discards silently (per the docs). Palette is the existing §12 set. The body figure is a crude placeholder; the app uses the traced SVGs.

Landing — final

Search at the top filters by name: templates and exercises. Tapping an exercise result starts an ad-hoc session and opens its logging screen. With an empty search you see your templates in a rail, then the ready-made tile grid. Start workout is a slim pinned bar.

Session screen — map first

The body map is the hero, and it shrinks as the list grows (3 or fewer exercises, 4–5, 6–7, 8+). Add exercises to the template session to see it. Under it is "keep logging": the exercise list with the next one outlined, then Add exercise. Template sessions show the planned muscles as dashed outlines that fill in as you log. Primary muscles fill strong, secondary muscles fill light. Tapping an exercise opens its logging screen.

Logging screen — one screen, the load types

Prefilled values are muted until you touch them. The check completes a set only when the required field is above zero; on an empty field it focuses it. Add set copies the previous row. Order: sets, Add set, Mark exercise done, Recent, See all.
