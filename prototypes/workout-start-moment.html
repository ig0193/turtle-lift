Workout — the start moment

Problem: tapping Start just swaps in a list, so nothing says "you are logging now". Four different answers. Each phone starts on the same landing: tap a template → Start, and also try the bottom Start workout bar. Then continue: pick an exercise, log a set, Mark done. Updated: the pulsing "Workout in progress" pill now appears only after Start logging, together with a display-only elapsed clock that starts at the same moment (also shown under the exercise name while logging). The clock is a prototype of the timer idea. It is not saved anywhere, and it conflicts with the current docs (see the note at the bottom).

P1 · Ready screen

Start opens a calm full-screen "Workout started" moment: pulsing dot, the title, the (empty) map and one big Start logging button. The tab bar is gone, so it is the only thing to do. Tapping Start logging shows the list (templates) or the exercise picker (empty start).

P2 · Live session, list on demand

Start goes straight to the live session screen: "Workout in progress", the big map (planned muscles dashed for templates), and a single Start logging button. The list is hidden. Tapping the button slides up a half-height sheet with the exercises, and the map stays visible behind it. The list screen only appears after you have logged something.

P3 · Go moment, then live session

A short (about 1s, tap to skip) celebratory "Workout started" beat: check pops in with a radiating burst, title fades up, then it lands on the P2 session screen. Borrowed from the workout-saved moment, so the start and the end of a workout feel like a pair.

P4 · Ready-to-log sheet

The conservative one. Start opens a bottom sheet "Ready to log?" with an optional name, the date and (for templates) the exercises. Start logging then goes straight to the list or the picker, like today.

Timer — what this prototype assumes

  • Display only. It is never stored, never shown in History, on the summary card or the share card. That keeps the docs' "no workout duration" rule for the data, and changes it only for the live screen.
  • It starts at Start logging, not at Start, so planning and naming time is not counted.
  • Open question: a session can stay open for days (persistence rule), so the clock needs a rule. Options: stop showing it after a few hours, or show it only while the session's date is today.
  • Open question: a rest timer (counts since the last completed set) is what people actually use mid-workout. Different feature, also out of scope today.

My pick

  • P2 as the base: live from the first frame, no extra screen, the list as a sheet, and the map as the backdrop. It also reuses the session screen we already have.
  • Add P3's burst as a very short, skippable beat only if P2 still feels too quiet.
  • P1 is the best fit if you want a natural place for naming the workout and picking the date before the first set. Fold P4's name and date into it if so.
