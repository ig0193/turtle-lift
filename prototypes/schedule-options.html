Profile — Personal / Schedule (v2)

Profile is now the fourth tab (ADR 0004), so the header avatar is gone. Chosen so far: A2 segmented Personal | Schedule, B1 simple chips + one time + Remind me, C1 explain-first permission sheet. The Schedule segment is now the whole screen inline (no second page to push), with a week summary panel on top. History-tab calendar changes are parked. Sample data: plan Mon · Wed · Fri, week starts Monday. Everything is clickable — tap the segment, the day chips, the Remind me switch, and use the "pretend today is" buttons under each Schedule phone.

Rule note. 00 §11 says anything computed from session rows lives on History. The summary panel is computed, so it is a deliberate exception: it is the feedback loop for the plan, not a stat. It would need to be recorded in the ADR, and when the History calendar lands the same figure must not be shown in both places.
